# aiom.shop

فروشگاه آنلاین تیشرت، راست‌چین و ریسپانسیو. HTML/CSS/JS خالص، بدون بیلد.

## اجرا
فایل `index.html` را باز کن، یا:

```bash
python3 -m http.server 8000
```

## ساختار
- `index.html` صفحه
- `css/style.css` استایل
- `js/products.js` محصولات (نام، قیمت، رنگ) و رسم تیشرت‌ها
- `js/app.js` فیلتر، سبد خرید، دیالوگ‌ها و انیمیشن‌ها

## قبل از انتشار
- نام، قیمت و توضیح محصولات نمونه است (`js/products.js`).
- «ثبت سفارش» ایمیل آماده به `hello@aiom.shop` باز می‌کند؛ درگاه پرداخت وصل نیست.
