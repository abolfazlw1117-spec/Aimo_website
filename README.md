# وب‌سایت AIMO

سایت کاملاً استاتیک (HTML + CSS + JavaScript ساده) برای معرفی توسعه‌دهندهٔ اپلیکیشن‌های اندروید. بدون Build، بدون نصب پکیج، بدون سرور یا API.

> **وضعیت:** این فایل‌ها آماده‌اند، ولی سایت تا وقتی طبق مراحل زیر منتشر نکنید، هنوز آنلاین نیست.

## فایل‌ها
- `index.html` صفحهٔ اصلی
- `style.css` ظاهر
- `script.js` تغییر زبان (فارسی/انگلیسی) و سال فوتر
- `.nojekyll` جلوگیری از پردازش Jekyll در GitHub Pages

## انتشار روی GitHub Pages
1. در GitHub روی **New repository** بزنید و یک مخزن **Public** بسازید (مثلاً `aimo-site`).
2. روی **Add file ▸ Upload files** بزنید و همهٔ فایل‌ها را در **ریشهٔ** مخزن آپلود کنید (`index.html` باید بیرون هر پوشه باشد). فایل `.nojekyll` اگر در لیست آپلود دیده نشد، مشکلی نیست.
3. **Commit changes** را بزنید.
4. به **Settings ▸ Pages** بروید.
5. در **Build and deployment**، گزینهٔ Source را روی **Deploy from a branch** بگذارید.
6. Branch را `main` و پوشه را `/ (root)` انتخاب کنید و **Save** بزنید.
7. یکی دو دقیقه صبر کنید و صفحه را رفرش کنید. آدرس سایت بالای همان صفحه نمایش داده می‌شود، معمولاً:
   `https://USERNAME.github.io/REPO/`
   (اگر نام مخزن دقیقاً `USERNAME.github.io` باشد، آدرس `https://USERNAME.github.io/` می‌شود.)
8. آدرس را باز کنید و بررسی کنید که کار می‌کند، سپس آن را در پروفایل توسعه‌دهندهٔ بازار وارد کنید.

## ویرایش محتوا
- **تماس:** در `index.html` بخش `contact` را با اطلاعات واقعی خودتان پر کنید.
- **حریم خصوصی:** بعد از ساخت صفحهٔ واقعی سیاست‌نامهٔ هر برنامه، پیوند آن را در بخش `privacy` بگذارید. تا آن زمان لینک ساختگی نگذارید.
- **برنامهٔ جدید:** یک `<article class="glass app">` در بخش `apps` کپی و متنش را عوض کنید.
- **نکتهٔ امنیتی:** هیچ توکن ربات، رمز یا اطلاعات شخصی داخل مخزن عمومی قرار ندهید.
